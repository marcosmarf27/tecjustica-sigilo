# Conjunto EXATO de bibliotecas que vai dentro do instalador.
#
# Por que este arquivo existe, e por que ele não é o requirements.txt:
#
# O Python embeddable do Windows não tem pip, então as bibliotecas são
# resolvidas de fora, com `--platform win_amd64 --only-binary=:all: --no-deps`
# (ver scripts/setup-python-embed.sh). O `--no-deps` é obrigatório: sem ele o
# resolvedor traz numpy 2.5 e quebra o presidio-analyzer, que exige `<2.5`.
#
# Só que `--no-deps` desliga o resolvedor por completo — o que não está listado
# aqui simplesmente não entra. Antes a lista era mantida à mão dentro do script
# e cobria cerca de um terço do necessário: faltavam thinc, click e mais de
# trinta pacotes. O embarcado saía sem conseguir nem importar o spaCy, e o
# instalador teria sido gerado assim, porque nada no build carregava o motor.
#
# Então este arquivo é o fecho transitivo INTEIRO, tirado de um `.venv` que
# comprova funcionar. Para regerar depois de mexer no requirements.txt:
#
#   .venv/Scripts/pip.exe freeze | grep -vE '^(antlr4|pt_core_news_lg)' \
#     >> python-backend/requirements-embed.txt
#
# Duas entradas ficam de fora do freeze e são tratadas à parte:
#
#   antlr4-python3-runtime  só existe como sdist na versão usada, então não
#                           passa pelo --only-binary. É Python puro: o script
#                           copia do venv.
#   pt_core_news_lg         vem de URL, não do PyPI. Está no fim deste arquivo.
#
# CUIDADO ao regerar: `pip freeze` copia o venv INTEIRO, e o venv deste projeto
# é puro de runtime de propósito — o requirements.txt não traz pytest nem
# nenhuma ferramenta de desenvolvimento. Se você instalar pytest (ou ruff, ou
# ipython) no .venv e regerar daí, essas bibliotecas passam a ser embarcadas no
# instalador e distribuídas ao usuário final. O `--no-deps` não protege contra
# excesso, só contra falta, e nada no build reclama de um pacote a mais: ele
# apenas engorda o `.exe`. Regere a partir de um venv limpo, ou remova as
# linhas de desenvolvimento à mão e confira o diff antes de commitar.
